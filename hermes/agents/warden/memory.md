### 路径格式
- `search_files` 底层是 Windows 原生 rg，不支持 MSYS2 `/d/` 路径。必须传 `D:/path` 格式。

### 文件安全
- 不允许修改 `$BLASTGAME_REPO` 下任何文件，除非用户明确授权
- Python 工具只通过 `write_ddc` 改 test/ 下的 asset
- 禁止写 funnel_b/、Library/、Temp/
- 禁止删除任何源数据文件 (Library/PackageCache/.meta/stage-data/assist/ref)

### Unity 相关
- Unity batch mode 报错时，优先检查 `tasklist | grep Unity.exe` 是否已在运行
- `AssetDatabase.Refresh()` 必须加 `ImportAssetOptions.ForceUpdate`，否则 Python write_ddc 后 Unity batch mode 可能读到旧缓存
- 禁止操作 Unity 项目核心文件：.meta 文件、Library/、Packages/packages-lock.json、manifest.json

### 配置同步
- `submit_batch_unity` 会从 `probe_configs.json` 覆盖 asset——改 asset 必须同步改 json

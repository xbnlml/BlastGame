# BlastGame 玩法机制概述

> 用于理解调参对象。不读本文直接猜机制 = 设计出脱离游戏实际的任务/探针。

## 核心玩法

**炮台自动射击消除游戏（非手动瞄准射击）。**

- 底部有多个 **槽位（slots）**，玩家放置/合成 **炮台（turrets）**
- 炮台**自动发射**彩色子弹向上攻击棋盘上的方块
- 方块三消/连锁消除
- 游戏自动推进，玩家主要做策略决策（放什么炮台、何时合成）

## 棋盘结构

```
16×17 网格
├── myStack: width/height/StackHeight/TowerValue/PoolValue/GateSize/SnakeSize
├── DynamicDifficultyConfigs[5] ← 我们要调的 4 参数
└── customCellDrawingListV2     ← 手摆方块布局（牌面）
```

## 关键字段

| 字段 | 含义 |
|------|------|
| `difficultyLevel` | 0=Normal, 1=Hard, 2=SuperHard |
| `startDifficulty (sd)` | 洗牌公式的偏移量。公式：`totalDifficultyIndex = difficultyLevel × levelDifficultyFactor + sd` |
| `sc/ratios/of` | 控制后续掉落方块的分布和难度 |
| `myStack` | 棋盘属性（宽/高/塔值/池值/门大小/蛇大小） |
| `TowerValue` | Block2x2 的颜色预算（该关未使用此机制则无效） |
| `PoolValue` | 候补队列预留量，控制方块补给 |
| `GateSize` | 门（Gate）机制的尺寸参数 |
| `SnakeSize` | 蛇（Snake）机制的尺寸参数 |

## 方块类型

| 类型 | 说明 |
|------|------|
| 普通块 | 彩色方块，三消消除 |
| Block2x2（大方块） | 2×2 大方块，整组消除 |
| Gate（门） | 从顶部下降，到底即失败 |
| Snake（蛇） | 链状方块，分 segment 逐个消除 |
| Pool（池方块） | 候补队列相关 |
| Key（钥匙） | 特殊收集目标 |
| 得分方块 | 计分特殊块 |
| 多色方块 | 一种特殊块 |
| collectable | 可收集物 |

## 炮台类型

| 类型 | 说明 |
|------|------|
| 普通炮台 | 基础炮台 |
| 三角炮台 | 三角形炮台，3 合 1 合成 |
| 相连炮台 | 连接型炮台 |
| 问号炮台 | 随机/隐藏炮台 |

## 核心规则

- 炮台**子弹数和棋盘上方块数是一一对应的**，不存在"省弹药"概念
- 方块清完时炮台也消耗完毕
- 任务设计不能基于步数/弹药/回合限制
- 游戏是**自动推进的**，玩家操控在炮台放置/合成/时机选择
- 连锁/连击是得分核心（`Game_Score_Logic.md`），combo 窗口由 `shootIntervalMs` 控制

## 任务设计限制

设计日常任务时，必须基于**每一关都有的通用机制**，不能假定特定特殊块组合存在。

## failBucketDistribution 正确理解（死亡分布→参数映射）

`campaign-summary` CSV 中的 10 个桶等分游戏总时间，统计**已死亡样本**中每段的死亡占比（条件分布）。

| 桶范围 | 时间段 | 对应阶段 | 能调什么 |
|--------|--------|---------|---------|
| 桶 0-1 | 0-20% | **初始牌面阶段** — 玩家在清预设的块 | 改关卡（重排牌面）。参数无法修补 |
| 桶 2 | 20-30% | **过渡阶段** — 初始块清完，第一个 shuffle 波次到达 | ratios 前段权重 + sd |
| 桶 3-5 | 30-60% | **中期 — 纯 shuffle** | of、ratios 分布 |
| 桶 6-9 | 60-100% | **后期 — 累积压力** | of、后段 ratios、sd |

**关键：ratios 前段≠failBucket 前段。** ratios 控制的是**后续掉落方块的分布**，而桶 0-1 的死亡是初始牌面导致的。ratios 前段影响的是过渡阶段（桶 2）。

**改关卡预判公式（仅用于高胜率档位 T1/T2 目标≥60%）：**
```
earlyDeath = 桶 0-1 占比和
阈值 = (1 - 目标WR) × 80%
如果 earlyDeath > 阈值 → 改关卡，不走 6 轮
否则 → 继续正常调试
```

**调参方向参考（非改关卡信号）：**
- 过渡段死亡 > 50% → 优先降 ratios 前段权重或降 sd
- 中期死亡 > 60% → 优先调 of 或换 ratios 分布  
- 后期死亡 > 60% → 优先降 of 或后段 ratios 放轻

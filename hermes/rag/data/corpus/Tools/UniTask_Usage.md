# UniTask 项目使用约定

> **AI 使用提示**：处理异步流程、延迟、取消或生命周期问题时读取本文；先确认对象/场景生命周期，不用异步任务替代玩法状态机。

## 适用范围

只记录项目中异步流程的接入边界，不作为 UniTask 通用 API 手册。

## 当前使用原则

- Unity 主线程逻辑使用 UniTask 编排异步步骤。
- 场景、窗口和对象池销毁时必须取消或结束关联任务。
- `await` 前确认对象生命周期和场景仍有效。
- 不用异步任务替代玩法状态机；状态由 Runtime/Sim 决定。
- 不在循环中创建无界任务或遗留未观察异常。

## 常见入口

| 场景 | 首选查找位置 |
|---|---|
| UI 动画序列 | 对应 View / `BlastUiAnimExecutor` |
| 场景切换 | `GameSceneSwitchCoordinator` |
| 道具流程 | `BlastGameController.PowerUps` |
| 放置动画 | `BlastStagePlacementAnim` |
| 资源加载 | `ResourcesManager` |

## 排查顺序

1. 确认任务是否在正确的生命周期内创建。
2. 确认对象销毁或重载时是否取消。
3. 确认异常是否被观察和记录。
4. 确认异步流程是否绕过了数据状态机。

具体用法以当前调用点和项目 API 为准，不在本文维护完整方法清单。

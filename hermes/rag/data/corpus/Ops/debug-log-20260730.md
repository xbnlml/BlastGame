### 架构决策

- **舍弃 Cron**：不用定时器轮询，用 `auto_loop.py` 单次启动循环（submit→wait→analyze→judge→probe→submit）直到6轮或合格。
- **Warden + Curator**：批跑前 Warden 机械检查（不过不给跑），批跑后 Curator 识别模式更新 skill 防再犯。
- **Profile 隔离**：blastgame skill/memory 放在 .hermes-blastgame profile，与 default profile 隔离。
- **判定统一**：judge_level.check_judgment 是唯一判定真理源，judgment-rules.md 标注为人类参考。
- **安静模式**：`DESIGN_PROBES_QUIET=1` 环境变量抑制 design_probes 的调试输出，保证 agent_analyze JSON 输出干净。
- **rules.json 单一规则源**：合并了 wrongbook.md (4条) + blastgame-level-optimizer 易犯错误表 (20条) → 24条机械可执行规则。

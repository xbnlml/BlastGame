# P1 问题修复记录 (2026-07-31)

## P1-3: preflight 未串联到 auto_loop

**问题**: auto_loop Phase 3 直接提交 Unity batch，未调用 `preflight.py` 验证 asset/probe/board。

**修法**:
- 在 auto_loop.py Phase 3 入口添加 `preflight.py submit --unit-only` 调用
- 失败时不阻止执行（auto 模式下 advisory），但记录到日志
- 行号: auto_loop.py ~line 572-591

## P1-5: retire_level 未串联到 auto_loop

**问题**: 满 6 轮改关卡后未自动调 `retire_level.py` 设时间防线 + 清 stage-data。

**修法**:
- 在 auto_loop Phase 5 满6轮分支添加 `retire_level.py {lv} --reason 'auto_loop: max rounds (6)'` 调用
- 行号: auto_loop.py ~line 648-657

## P1: 管道去重 — auto_loop 与 submit_batch_unity 重复跑 agent pipeline

**问题**: submit_batch_unity.py 步骤 4-6 内部运行 agent_data、agent_analyze、agent_review。auto_loop 也单独运行 agent_analyze (Phase 1) 和 judge_level (Phase 5)，导致池子刷新和判定各跑两份。

**修法**:
- submit_batch_unity.py 新增 `--skip-agent-pipeline` flag，跳过步骤 4-6
- auto_loop.py 传 `--skip-agent-pipeline` 给 submit_batch_unity
- auto_loop 自行统筹：Phase 1 = agent_analyze, Phase 4 = dump_level_pools, Phase 5 = judge_level

## P1: auto_loop `current_pending` NameError

**问题**: `current_pending` 在 Phase 3 preflight 块中引用（line 578），但定义在后面（原 line 595）。

**修法**:
- `current_pending = sorted(pending, key=int)` 移至 Phase 3 入口第一行 (line 572)
- 删除后面重复定义

## P1: read_target_wr.py f-string 语法错误

**问题**: f-string 内不能使用反斜杠转义引号 (`t[\"diff\"]`)，Python 3.12+ 报 SyntaxError。

**修法**:
- 提取 `diff = t['diff']` 变量，f-string 中直接引用 `diff`

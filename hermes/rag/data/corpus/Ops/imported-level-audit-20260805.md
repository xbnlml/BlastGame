## 三方对比法（核对任何已入库关）

```
Excel 记录（胜率+配置） vs read_ddc(lv) asset 当前配置 vs 池子同配置 WR（filter_verified 匹配四元组）
```

### 关键陷阱
1. **Excel 胜率列是小数不是百分数**（0.9=90%、0.2575=25.75%）——比较前 ×100，否则全误报（实测 150 关全报"T5<5%"）
2. **早期记录（备注为空 = 7-31 判定标准定稿前）可能不达标**——当时无 T5<5% 硬红线/无目标偏差检查
3. **Excel 与 asset 可能完全脱节**——asset 后来被改（write_ddc/探针/重新调优）但 Excel 没同步
4. **asset 可能是探针残留**——auto_loop/apply_probes 写入但批跑没完成

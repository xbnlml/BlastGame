# Blast 打点字段说明（待补充版）

## 文档信息
- 版本：v0
- 维护人：
- 更新日期：
- 口径说明：
  - 回放坐标：0-based（内部）
  - 打点坐标：1-based（上报），无值记 `0`
  - 布尔统一上报为 `int`：`0/1`
  - `sd` 取值范围：`0~5`

---

## 1. 事件：`place_slot`（放置棋子）
- 触发时机：槽位变化时
- 事件模块：click

### 字段
| 字段名 | 类型 | 是否必填 | 默认值 | 取值/口径 | 业务含义（待补） | 备注（待补） |
|---|---|---|---|---|---|---|
| level | int | 是 | - | >=1 |  |  |
| cycle | int | 是 | 0 | >=0 | 服务器记录的该关失败次数 | 触发时读取服务端口径 |
| col | int | 是 | 0 | 1-based，无值=0 | 点击格子在 stage 区域中的原始列坐标（转换后上报） | 与 `row` 共同标识本次点击位置 |
| row | int | 是 | 0 | 1-based，无值=0 | 点击格子在 stage 区域中的原始行坐标（转换后上报） | 与 `col` 共同标识本次点击位置 |
| deltaMs | int | 是 | 0 | >=0 | 与上一次点击之间的时间间隔（毫秒） | 两次点击间隔 |
| slots_total | int | 是 | 0 | >=0 | 当前全部 slot 区域的鸽子总数（含复活道具导致的扩展区域） | 会动态变化：有时存在扩展 slot 格子，有时无 |
| slots_taken | int | 是 | 0 | >=0 | 当前所有区域中非空 slot 的数量 | 随盘面与复活扩展状态实时变化 |
| is_merge | int | 是 | 0 | 0=否,1=是 |  |  |
| is_tap | int | 是 | 1 | 0=否,1=是 |  | 玩家触发建议=1 |
| sd | int | 是 | 0 | 0~5 | 本关用于计算关卡难度的 tier 值 | 难度分层口径 |
| use_boost | int | 是 | 0 | 0无,1磁铁,2魔法棒,3锤子,4回溯 | 本次是否使用道具及道具类型 | 道具导致的盘面最终生效变化也计入槽位变化；仅临时待点击态（如锤子待点击）不计入 |

## 2. 事件：`load_level`（加载关卡）
- 触发时机：加载完成后
- 事件模块：enter_level

| 字段名 | 类型 | 是否必填 | 默认值 | 取值/口径 | 业务含义（待补） | 备注（待补） |
|---|---|---|---|---|---|---|
| level | int | 是 | - | >=1 |  |  |
| cycle | int | 是 | 0 | >=0 | 服务器记录的该关失败次数 | 触发时读取服务端口径 |
| lives | int | 是 | 0 | >=0 | 玩家当前 health | 取触发时玩家实时血量 |
| sd | int | 是 | 0 | 0~5 | 本关用于计算关卡难度的 tier 值 | 与关卡难度分层一致 |
| load_time | int | 是 | 5000 | 固定=5000(ms) | 加载耗时（当前按 5 秒写死） | 先写死 5s，后续可替换为真实耗时 |

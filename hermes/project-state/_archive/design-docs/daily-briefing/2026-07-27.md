🔥重磅

1. [官方] Kimi K3 开源权重提前一天发布 — Moonshot AI 于7月26日开放了 2.8T 参数 MoE 模型 Kimi K3 的完整权重，比此前承诺的7月27日提前约24小时。该模型拥有 100 万 token 上下文窗口，采用 MXFP4 量化感知训练，是全球迄今为止最大的开源权重模型。Together AI 和 Modal 已同步提供 Day-0 托管服务，开发者可通过 API 按需调用，API 定价仅为 $3/$15 每百万 token（输入/输出），显著低于同级竞品。Moonshot 联合创始人在 r/LocalLLaMA AMA 中确认开源权重与付费 API 使用同一量化方案，自托管推理质量一致。
来源：kimi.com/blog/kimi-k3 | huggingface.co/moonshotai/Kimi-K3-MXFP4

2. [媒体] Nvidia 拟为 OpenAI 提供 2500 亿美元数据中心担保 — 据 WSJ/Bloomberg 7月26-27日报道，Nvidia 正洽谈为 OpenAI 位于俄亥俄州的数据中心项目提供最多 2500 亿美元的财务担保。该项目由 SoftBank 主导，总造价超 5000 亿美元，包含 10 吉瓦电力容量。若计入 Nvidia 芯片采购融资，总额可达 3500 亿美元。这将是史上最大规模的 AI 基础设施投资，标志着芯片巨头与模型公司的深度绑定。
来源：bloomberg.com/news/articles/2026-07-26/nvidia-in-talks-on-250-billion-backing-for-openai-hub

3. [媒体] Stripe 拟以约 100 亿美元收购 OpenRouter — 据 WSJ 7月24日报道，支付巨头 Stripe 正深入洽谈收购 AI 模型聚合平台 OpenRouter，估值约 100 亿美元，是其 5 月 B 轮 13 亿美元估值的近 8 倍。OpenRouter 目前月处理超 100 万亿 token，全球用户超 800 万。若交易完成，Stripe 将从支付管道延伸为 AI Agent 经济的默认路由和计费基础设施。
来源：wsj.com | thenextweb.com/news/stripe-openrouter-10-billion-ai-model-marketplace-acquisition

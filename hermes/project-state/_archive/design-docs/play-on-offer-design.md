# 复活礼包（Play On Offer）触发方案

## 一、触发

关卡内进度 ≥ 50%，满足即弹，100%，不限难度，不限等级。

死亡界面上金币复活和礼包并列展示，玩家自选。

## 二、礼包

| 档位 | 价格 | 内容 |
|------|------|------|
| Offer0 | $0.99 | 复活 + 1000金币 |
| Offer1 | $1.99 | 复活 + 1500金币 + 1种道具 |
| Offer2 | $3.99 | 复活 + 3000金币 + 2种道具 |
| Offer3 | $6.99 | 复活 + 5000金币 + 4种道具各1 |
| Offer4 | $9.99 | 复活 + 8000金币 + 4种道具各2 |

## 三、档位判定

### 消费档（上限）

| 分层 | 累计消费 | 消费档 |
|------|---------|--------|
| 0元党 | $0 | Offer1 |
| 小R | $0.01–$9.99 | Offer2 |
| 中R | $10–$99.99 | Offer3 |
| 大R | $100+ | Offer4 |

累计消费跨过门槛 → 消费档自动升。

### 降档

两条路径独立计数。每次死亡最多降 1 档。

| 路径 | 条件 | 幅度 |
|------|------|------|
| 拒绝降档 | 当前档位连拒 10 次 / 第 2 次降需 20 次 | 降 1 档 |
| 时间降档 | 距首次登录（0元党）或上次付费 ≥ 7 天 | 降 1 档 |

连拒仅统计当前档位。买了 → 拒数清零。档位变化 → 拒数清零。消费档升级不触发清零。

### 回弹

买了 → 回弹计数 +1。满 3 次 → 升 1 档（不超过消费档），降档等级重置回 10 次。

回弹中再次降档 → 回弹计数清零。

### 边界

- 下限 Offer1，再降 Offer0
- 上限消费档

## 四、总结

```
档位 = 当前档（消费档为上限）
     每次死亡：≥7天未付 → 降1档 / 当前档连拒10/20次 → 降1档
     每次购买：回弹+1 → 满3次 → 升1档，降档等级重置回10

拒数仅限当前档位，档位变化清零
上限消费档，下限 Offer1 → Offer0
```

## 五、参数

| 参数 | 默认值 |
|------|--------|
| 进度阈值 | 50% |
| 连拒降档次数 | 第1次10次，第2次20次 |
| 时间降档天数 | ≥ 7天 |
| 回弹需购买次数 | 3次 |
| Offer0 价格/金币 | $0.99 / 1000 |

全部服务端可配。

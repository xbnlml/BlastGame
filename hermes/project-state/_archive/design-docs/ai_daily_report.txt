📚今日一课：Model I/O 与模型接入

Model I/O 是 LangChain 中最基础的核心模块，定义了三步流程：Format（输入格式化）-> Predict（模型调用）-> Parse（输出解析）。关键认知：LangChain 将模型分为 LLM（文本补全）、Chat Model（多轮对话）、Embeddings（向量化）三类，实际开发最常用 Chat Model。调用后返回的不是字符串而是 AIMessage 对象，正文在 response.content。参数中 temperature 控制随机性，max_tokens 控制长度与费用。接入方式有三种：官方 SDK 直连、LangChain provider 类、统一入口 init_chat_model，新项目推荐后者。记住：底层模型能力、Prompt 设计与上下文质量比单纯调参更重要。

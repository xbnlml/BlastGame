# Gap 评分公式（`_gap_score`）

`blastgame-judgment` 使用的 `_gap_score` 内部实现参考。

## 罚分公式

```python
for each gap (g):
    if g < 15:
        score += (15 - g) * 5    # 基本罚分：每缺 1pp = 5 分
    if g < 10:
        score += (10 - g) * 10   # 额外罚分：gap 严重时加罚
```

## 设计原则

- **连续性：** gap=10 处无跳变（基本罚分 25 分，g<10 额外加罚从 0 开始连续增加）
- **优先级：** gap 质量 ≈ 目标接近度，gap<10 时 gap 优先
- **≈5% 对齐：** gap=12pp 罚 15 分，约等于「每档离目标 5%」的罚分（3 档 × 5pp = 15 分）

## 罚分速查

| gap | 基本 (15-g)×5 | 额外 (10-g)×10 | 总 |
|-----|--------------|----------------|-----|
| 15pp | 0 | 0 | **0** |
| 14pp | 5 | 0 | **5** |
| 13pp | 10 | 0 | **10** |
| 12pp | 15 | 0 | **15** |
| 11pp | 20 | 0 | **20** |
| 10pp | 25 | 0 | **25** |
| 9pp | 30 | 10 | **40** |
| 8pp | 35 | 20 | **55** |
| 7pp | 40 | 30 | **70** |
| 6pp | 45 | 40 | **85** |
| 5pp | 50 | 50 | **100** |
| 3pp | 60 | 70 | **130** |

## Normal 模式

仅检查 T1-T3 和 T3-T5 两个 gap。T1=T2、T4=T5 同难度，不独立检查。

## 硬违规（独立于 `_gap_score`，在搜索循环中处理）

- 任意 gap < 5 → 跳过组合
- 任意 gap > 40（仅 Hard/SuperHard） → 跳过组合
